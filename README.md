# Digital Marketing Agency Landing Page

A professional, modern landing page for a digital marketing agency showcasing services, case studies, and client testimonials. Built with semantic HTML5, modern CSS, and vanilla JavaScript for optimal performance and accessibility.

## 🎯 Project Overview

This landing page is designed to help digital marketing agencies establish a strong online presence and convert visitors into clients. It features a clean, responsive design with sections for services, about information, case studies, testimonials, and contact forms.

### Key Features

- **Responsive Design**: Mobile-first approach ensuring perfect display on all devices
- **Semantic HTML5**: Proper structure with ARIA landmarks for accessibility
- **Performance Optimized**: Fast loading times with optimized assets
- **SEO Ready**: Meta tags, structured data, and semantic markup for search engines
- **Accessible**: WCAG compliant with keyboard navigation and screen reader support
- **Modern CSS**: Custom properties, flexbox, and grid layouts
- **Vanilla JavaScript**: No framework dependencies for minimal bundle size

## 🛠️ Technology Stack

- **HTML5**: Semantic markup with proper sectioning elements
- **CSS3**: Modern styling with custom properties and responsive design
- **JavaScript (ES6+)**: Vanilla JS for interactions and animations
- **Build Tools**:
  - PostCSS for CSS processing and optimization
  - Terser for JavaScript minification
  - html-validate for HTML validation
  - Autoprefixer for browser compatibility
  - cssnano for CSS minification

## 📋 Prerequisites

- Node.js >= 18.0.0
- npm >= 9.0.0
